# برمجة العمليات الحسابية في سكراتش · الصف السادس

عرض تفاعلي لدرس «برمجة العمليات الحسابية» (المهارات الرقمية، الوحدة الرابعة، ص 142–152) لحصتين.

- **العرض المباشر:** https://mnsor0-dev.github.io/Grade-6/
- **الملف:** `index.html`، وهو ملف واحد يعمل في المتصفح دون تثبيت. يمكن تنزيله وفتحه محلياً.
- **التنقل:** الأسهم أو «التالية/السابقة». اضغط «▶ الحصة الأولى/الثانية» لبدء ساعة الحصة، وF11 لملء الشاشة.

تعليمات العمل على المشروع في `AGENTS.md`. مواد المراجع (الكتاب ودليل المعلم) لا تُرفع إلى المستودع.
